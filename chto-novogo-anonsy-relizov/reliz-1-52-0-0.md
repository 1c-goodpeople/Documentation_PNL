## Отчёт о розничных продажах: статья дохода по соответствию

В **Бухгалтерии предприятия** при формировании доходов P&L по отчёту о розничных продажах изменён порядок выбора статьи. Для каждой строки документа используется первая заполненная статья:

1. Статья P&L в строке документа.

2. Статья P&L в шапке документа.

3. Статья из регистра «Соответствие параметров и статей ДДС».

4. Типовая статья ДДС в шапке документа.

Если для строки найдено подходящее соответствие, в том числе по номенклатурной группе, оно теперь применяется даже при заполненной типовой статье ДДС. Порядок действует для продажи собственных и комиссионных товаров и услуг, а также для возвратов в этом документе.

Чтобы обновить движения P&L по уже проведённым документам, повторно запустите заполнение по правилам. Бухгалтерские проводки при этом не пересчитываются.

## Финансовый план БДДС: заполнение по проектам

В документе **«Финансовый план БДДС»** появилась команда **«Заполнить по проектам»**. Она переносит плановые суммы из смет и графиков смет проектов за год планирования по статьям ДДС выбранной структуры отчёта. Поступления отражаются со знаком «плюс», выплаты -- со знаком «минус».

При детализации **«Проект и контрагент»** поступления показываются по проектам и контрагентам, а выплаты -- по проектам. Без детализации суммы собираются по статьям и месяцам. Если в плане уже есть суммы, при заполнении можно очистить их или дополнить существующие данные. Для детализации **«Контрагент и договор»** команда недоступна.

## Кошелёк: учёт НДС в операциях

В карточке кошелька появился флажок «Вести учёт НДС». После его включения в операциях поступления и списания можно указать ставку и сумму НДС. Сумма НДС входит в полную сумму операции: при выборе ставки она рассчитывается автоматически, при необходимости её можно изменить вручную. Для валютного кошелька сумма НДС указывается в валюте кошелька.

[Подробнее об учёте НДС по кошельку](./../p-l/dengi/koshelek/_index.md)

## MCP: обновлены настройки и подключение к ИИ

Обновлён блок **MCP** для работы ИИ-помощника с данными P&L. Администратор может задать структуры отчётов и версии финансовых планов, выдать сотрудникам личные токены и настроить показ наименований организаций, контрагентов, людей и договоров. Помощнику доступны показатели ОПиУ, ДДС, БДР и БДДС, платёжный календарь, проекты и договоры. MCP работает только на чтение.

Для подключения подготовлены переносимые папки для **Windows и macOS** со встроенным Node.js и проверкой связи с базой. Адаптер получает обновления из расширения P&L; устанавливать Node.js отдельно не требуется.
