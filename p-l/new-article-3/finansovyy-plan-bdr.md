**БДР (Бюджет доходов и расходов)** -- это финансовый план, который отражает ожидаемые доходы, расходы и финансовый результат (прибыль или убыток) компании за определённый период.

В отличие от БДДС (который отвечает за движение денег), БДР отвечает за **эффективность деятельности**:

-  Позволяет **планировать прибыль** -- видеть, сколько компания заработает и потратит.

-  Помогает **контролировать рентабельность** -- сравнивать плановую и фактическую прибыль, выявлять убыточные направления.

-  Служит основой для **управленческих решений** -- оценивать экономическую целесообразность проектов, подразделений, видов деятельности.

-  Даёт возможность **анализировать структуру затрат** -- видеть, какие статьи расходов растут, а какие можно сократить.

Совместно с БДДС БДР даёт полную картину: первый показывает ликвидность, второй -- прибыльность.

2. Выберите пункт **«Финансовый план БДР»**.

3. Нажмите **«Создать»**, чтобы начать формирование нового бюджета.

### Шаг 2. Заполнение верхних параметров

При создании укажите обязательные параметры:

| Параметр                     | Описание                                                                                                                                 |
|------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|
| **Версия финансового плана** | Название версии (например, «План 2026», «Оптимистичный»). Можно создавать несколько версий для сценариев и сохранять исторические данные |
| **Организация**              | Выберите организацию, для которой планируете БДР                                                                                         |
| **Год планирования**         | Укажите начало года в формате `01.01.2026` (всегда указывается первое число года)                                                        |
| **Структура отчёта**         | На основе этой структуры формируется таблица БДР. Структура определяет, какие статьи доходов и расходов будут отображаться               |

### Шаг 3. Дополнительные разрезы (аналитика)

Вы можете детализировать планирование, указав:

-  **Подразделение** -- планирование по ЦФО.

-  **Направление деятельности** -- планирование по видам бизнеса.

Если вы хотите видеть сводные данные по всей организации **и одновременно** в разрезе направлений, создайте несколько финансовых планов с **одной и той же версией**, но с разными подразделениями/направлениями. Тогда в отчёте данные сгруппируются как по организации, так и по выбранным разрезам.

## Заполнение данных в БДР

#### Правила ввода сумм:

-  **Все суммы (и доходы, и расходы) заносятся положительными числами.** В отличие от БДДС, здесь не используется знак «минус».

-  Заполняются только **статьи** (конечные строки), а не группы.

-  **Группы, которые являются формулами** (например, «Прибыль»), **заполнять не нужно** -- они рассчитаются автоматически при формировании отчета.

#### Интерфейс и ввод:

-  Данные вводятся в ячейки таблицы так же просто, как в Excel.

-  В контекстном меню (правая кнопка мыши) доступны три вспомогательные команды:

| Команда                 | Действие                                                                                                       |
|-------------------------|----------------------------------------------------------------------------------------------------------------|
| **Распределить сумму**  | Указываете общую сумму и период (например, с января по декабрь) -- программа равномерно разнесёт её по месяцам |
| **Перенести сумму**     | Переносит часть суммы из одной ячейки/месяца в другой (например, с июня на июль)                               |
| **Указать комментарий** | Добавляет примечание к ячейке (ячейка выделяется зелёным)                                                      |

## Где используется БДР

Созданный БДР применяется в основном в **отчёте о прибылях и убытках (P&L)**. В варианте отчёта выберите **«План-факт»**. В отборах укажите версию финансового плана.
