## Общее

MCP соединяет модуль P&L в 1С с ИИ-помощником. Вы задаёте вопрос обычными словами, а помощник получает нужные данные из вашей базы и отвечает с цифрами. Например: «Покажи выручку и чистую прибыль по месяцам за первое полугодие» или «Какие платежи просрочены сегодня?»

Помощник может запросить ОПиУ, ДДС, БДР, БДДС, платёжный календарь, сведения о проектах и договорах. MCP P&L работает **только на чтение**: через него ИИ не изменяет данные в 1С.

| Данные | Пример вопроса |
|---|---|
| ОПиУ | «Как менялась выручка и чистая прибыль по месяцам?» |
| ДДС | «Сколько денег поступило и сколько потратили в июне?» |
| БДР и БДДС | «Сравни план и факт за второй квартал». |
| Платёжный календарь | «Какие платежи просрочены?» |
| Проекты | «Какие проекты вышли за смету?» |
| Договоры | «Какие платежи запланированы по договору?» |

Цифры ОПиУ, ДДС и бюджетов зависят от структур отчётов, которые настроены в этой базе.

:::info

MCP доступен в версии **КОРП**. Для подключения нужна база 1С с актуальным расширением P&L и программа с поддержкой локального MCP на компьютере пользователя.

:::

Дальше два набора шагов. **Администратор** готовит базу и выдаёт доступ. **Пользователь** один раз подключает полученную папку к своей программе с ИИ.

## Для администратора

### 1. Подготовьте базу и публикацию

1. Установите актуальное расширение `ХЛ_PNL` в нужную базу 1С. Если расширение уже стоит, обновите его обычным для вашей базы способом.
2. Опубликуйте базу на веб-сервере через **Конфигуратор → Администрирование → Публикация на веб-сервере**. Если база уже опубликована, проверьте её публикацию.
3. Включите **«Публиковать HTTP-сервисы расширений по умолчанию»**. Без этого HTTP-сервис P&L не будет доступен.
4. Запишите адрес для подключения: `https://ваш-сервер/имя-публикации/hs/mcp_pnl`. Проверьте, что сервер доступен **с компьютера пользователя**. Адрес с `localhost` подходит только тогда, когда 1С и ИИ работают на одном компьютере. Для подключения через сеть используйте HTTPS.

В адресе, который получит пользователь, **нет** окончания `/v2`.

### 2. Дайте 1С права на чтение

Подготовьте логин и пароль пользователя информационной базы 1С для подключения. Можно завести отдельного служебного пользователя, например «MCP-ассистент». Этим логином могут пользоваться несколько человек: каждого из них дополнительно определяет **личный токен MCP**.

Пользователю 1С нужны право обращения к сервису **«МСР: агент (только чтение)»** и права чтения тех данных P&L и 1С, о которых будут спрашивать помощника. Право агента само по себе не даёт доступ ко всем финансовым данным. Проверьте действующие права на своей базе.

### 3. Включите MCP и настройте данные

Откройте **P&L → Настройки → MCP** и включите **«Использовать MCP сервис»**. В разделе **«Данные для ИИ — общие настройки»** укажите действующие структуры ОПиУ и ДДС, месяц начала их действия и, если нужны планы, версии финансовых планов для БДР и БДДС.

Если для запрошенного месяца структура не задана, ИИ получит ошибку `STRUCTURE_NOT_SET`. Если структуры менялись, сохраните настройки с месяца начала действия каждой структуры.

### 4. Выдайте человеку личный токен

1. На странице MCP нажмите **«Настроить доступ пользователей к MCP»**.
2. В списке нажмите **«Создать»** и выберите человека из справочника **«Пользователи»**. При необходимости добавьте комментарий, чтобы понимать, кому выдали доступ.
3. Выберите, показывать ли обычные наименования **организаций, контрагентов, физических лиц, сотрудников и договоров**. Когда переключатель выключен, для первых четырёх категорий передаётся наименование P&L, если оно заполнено, иначе код; для договора — код.
4. Сохраните запись, нажмите **«Сформировать токен»**, затем **«Скопировать токен»**. Передайте токен именно этому человеку.

Исходный токен виден **только сразу после выпуска**. При повторном открытии записи пустое поле токена — нормальное поведение: в базе хранится его хеш. Если токен утрачен, выпустите новый; старый сразу перестанет работать на всех устройствах. Чтобы закрыть доступ человеку, удалите его запись из списка. В каждой базе у него будет отдельный токен.

Переключатели меняют **наименования в структурированных ответах**. Они не ограничивают суммы и другие доступные данные. Текст, который кто-то вручную вписал в комментарий или назначение платежа, не скрывается.

### 5. Проверьте подключение и передайте данные

После выдачи токена проверьте подключение с компьютера, которому доступна публикация базы: возьмите чистую папку MCP, заполните в ней четыре строки файла `Настройки.txt` и запустите `Проверить.cmd`. Успешный результат — **«Связь с 1С есть»**. Проверка нужна именно с логином, паролем **и** токеном. Простое открытие `/health` в браузере без токена может вернуть `401` даже при исправной публикации.

Передайте пользователю:

- ссылку на актуальный архив папки MCP для Windows;
- адрес вида `https://ваш-сервер/имя-публикации/hs/mcp_pnl`;
- логин и пароль 1С для подключения;
- его личный токен MCP.

### Если проверка не прошла

| Что произошло | Что проверить |
|---|---|
| Нет связи с 1С | Доступен ли сервер с этого компьютера, опубликована ли база и включена ли публикация HTTP-сервисов расширений. |
| `401` | Верны ли логин, пароль и токен **этой** базы; не был ли токен заменён. |
| `403` или сообщение о правах | Включён ли MCP и хватает ли пользователю 1С прав на сервис и данные. |
| `404` | Верен ли адрес публикации и окончание `/hs/mcp_pnl`. |
| `STRUCTURE_NOT_SET` | Задана ли структура отчёта для запрошенного месяца. |

## Для пользователя

### Сначала проверьте, подходит ли ваша программа с ИИ

Эта папка работает с **программой на вашем компьютере, которая умеет запускать локальный MCP-сервер (`stdio`)**. Например, это может быть Claude Desktop, Claude Code, Cursor, VS Code с поддержкой MCP или Codex с локальным MCP-подключением. Нужна именно поддержка локальных MCP в выбранной программе. **Обычный чат в браузере или приложение на телефоне не запустят папку с вашего компьютера.** При этом сама модель ИИ может работать через интернет: локально запускается папка MCP.

Эти шаги рассчитаны на **Windows**. Расширение 1С устанавливает администратор; скачивать его вместе с папкой не нужно.

### 1. Получите папку и доступ

Администратор даст вам ссылку на архив, адрес базы, логин, пароль и **личный токен**. Токен относится к конкретной базе. Если у вас две базы, попросите отдельный токен для каждой.

**Скачать папку MCP для Windows:** **[ссылка будет добавлена]**.

Распакуйте архив в свою папку на компьютере, например в **Документы**. Внутри уже есть нужный `node.exe`: **устанавливать Node.js отдельно не нужно**. После подключения к ИИ не переносите папку — программа будет запускать файлы по её текущему пути.

### 2. Заполните четыре строки

Откройте в папке файл `Настройки.txt` обычным Блокнотом. После каждого знака `=` впишите данные от администратора:

```text
Адрес=https://ваш-сервер/имя-публикации/hs/mcp_pnl
Логин=логин 1С
Пароль=пароль 1С
Токен=личный токен MCP
```

Сохраните файл. Пароль может быть пустым, если так настроено подключение к 1С. Адрес и токен должны быть от **одной и той же базы**.

### 3. Проверьте связь с 1С

Дважды нажмите `Проверить.cmd` в этой же папке. Если появилось сообщение **«Связь с 1С есть»**, переходите дальше. Если появилась ошибка, отправьте администратору **текст ошибки**. Не отправляйте заполненный `Настройки.txt`: в нём находятся пароль и токен.

### 4. Подключите папку к ИИ

Откройте установленную программу с ИИ. Скопируйте **полный путь к распакованной папке** и вставьте в текст ниже вместо `<путь к папке>`. Затем отправьте весь текст своему ИИ:

> Помоги подключить P&L MCP к твоей программе на Windows. Папка находится здесь: `<путь к папке>`. Данные для входа уже записаны в `Настройки.txt`. Не открывай этот файл и не показывай его содержимое в чате.
>
> Проверь, поддерживает ли твоя программа локальный MCP через `stdio`. Если да, добавь сервер с именем `pnl-mcp`: команда — полный путь к `node.exe` в этой папке, единственный аргумент — полный путь к `bootstrap.mjs` в ней же. Сохрани мои другие MCP-подключения. Если ты не можешь изменить настройки сам, покажи мне, куда нажать в этой программе.
>
> После подключения перезапусти MCP или попроси меня перезапустить программу. Вызови инструменты `health` и `list_structures` и скажи, есть ли связь с моей базой. Ничего не изменяй в 1С.

Если ИИ попросит заполнить настройки MCP вручную, укажите:

| Поле | Что указать |
|---|---|
| Тип подключения | Локальный MCP (`stdio`) |
| Имя | `pnl-mcp` |
| Команда | Полный путь к `node.exe` **в распакованной папке** |
| Аргумент | Полный путь к `bootstrap.mjs` **в той же папке** |

Пароль и токен в настройках ИИ писать повторно не нужно: запускатель берёт их из `Настройки.txt`. После добавления MCP перезапустите программу с ИИ или переподключите MCP. Теперь можно спросить, например: **«Через P&L MCP покажи выручку и чистую прибыль по месяцам за этот год»**.

### Что делать потом

Новые инструменты и обновления адаптера приходят из расширения P&L в вашей базе. В обычной работе повторно скачивать папку не нужно. Если после обновления базы программа попросит переподключить MCP или перезапуститься, сделайте это.

Если `Проверить.cmd` показывает связь, а ИИ не видит MCP, проверьте поддержку **локального `stdio`**, пути к `node.exe` и `bootstrap.mjs` и перезапустите ИИ. Если токен потерян или перестал работать, попросите администратора выпустить новый.

Заполненная папка содержит пароль и токен. Храните её у себя и не пересылайте другим людям; для другого пользователя нужен чистый архив и его личный токен.
