Блок **MCP** открывает данные модуля P&L для ИИ-ассистентов: Claude, Cursor и других программ, которые поддерживают протокол MCP (Model Context Protocol). После настройки ассистенту можно задавать вопросы о финансах компании обычным языком, а он сам берёт нужные цифры из базы 1С.

:::info 

Блок доступен в версиях **КОРП** и **КОРП BI**.

:::

## Для чего нужен блок

Без MCP, чтобы ответить на вопрос «какая у нас чистая прибыль за полгода и почему в марте она просела», нужно открыть отчёт, выставить период и структуру, выгрузить данные и разобрать их вручную.

С MCP вопрос задаётся ассистенту в чате. Ассистент сам запрашивает у 1С нужные строки отчёта за нужный период, сравнивает месяцы, раскладывает сумму по проектам или статьям и отвечает с цифрами. По просьбе он строит график или дашборд в оформлении P&L.

Ассистент получает только те данные, которые запросил для ответа. Изменять данные в базе он не может: сервис работает только на чтение.

## Что получит клиент

Ассистенту доступны данные основных блоков модуля:

| Блок | Что можно спросить |
|---|---|
| ОПиУ | Выручка, расходы, EBITDA, чистая прибыль, рентабельность за любой период, по месяцам, кварталам, по организациям, проектам, статьям, контрагентам |
| БДР | Плановые значения по строкам бюджета и план-факт с отклонением и процентом исполнения |
| ДДС | Поступления и платежи по строкам отчёта ДДС, по видам деятельности и в любом разрезе |
| БДДС | План движения денег и план-факт |
| Платёжный календарь | Список платежей, выполнено, запланировано и просрочено, статус оплаты и согласования |
| Проекты | Список проектов, карточка проекта, план по смете против факта |
| Договоры | Список договоров, карточка, график платежей и его исполнение |
| Дашборды | Готовые графики и дашборды в фирменном оформлении P&L. Файл открывается в браузере и вставляется в «Поле HTML документа» 1С без правок |

Примеры вопросов:

-  «Что у нас по выручке с января по июнь помесячно?»

-  «Покажи чистую прибыль и рентабельность за полугодие и построй график».

-  «Сравни план и факт по БДР за второй квартал. Где самое большое отклонение?»

-  «Какие платежи просрочены на сегодня?»

-  «Какие проекты отстают от сметы по расходам?»

Суммы считаются по тем же правилам, что и отчёты модуля: по структуре отчёта, без НДС, с формулами и распределёнными косвенными расходами.

## Как настроить

### Шаг 1. Опубликуйте базу на веб-сервере

Ассистент обращается к 1С через HTTP-сервис модуля. Если база уже опубликована на веб-сервере для веб-клиента или обменов, используйте эту публикацию.

При публикации базы в Конфигураторе (**Администрирование → Публикация на веб-сервере**) включите флажок **«Публиковать HTTP сервисы расширений по умолчанию»**. Без него сервис модуля не будет доступен снаружи.

Адрес сервиса имеет вид:

`http://<адрес сервера>/<имя публикации>/hs/mcp_pnl/v2`

### Шаг 2. Создайте пользователя для ассистента

Заведите в 1С отдельного пользователя, под которым ассистент будет обращаться к базе, например «MCP-ассистент». Отдельный пользователь нужен, чтобы не передавать ассистенту логин и пароль сотрудника.

Назначьте пользователю роли:

1. **МСР: агент (только чтение)** -- доступ к сервису MCP.

2. **Управление финансами (Аудитор)** -- чтение данных модуля P&L.

### Шаг 3. Включите сервис в настройках P&L

1. Откройте **1C:P&L → Настройки** и выберите блок **«MCP»**.

2. Установите флажок **«Использовать MCP сервис»**. Пока флажок снят, сервис отклоняет все запросы ассистента.

3. В поле **«Адрес сервиса»** указан адрес, который понадобится на шаге 4.

### Шаг 4. Укажите структуры отчётов

Ассистент считает данные по структуре отчёта. Укажите, какую структуру брать по умолчанию.

В группе **«ОПиУ»**:

1. **Действует с месяца** -- месяц, с которого действует настройка.

2. **Структура отчета ОПиУ** -- структура, по которой считаются ОПиУ и БДР.

3. **Версия финплана (БДР)** -- версия финансового плана для плановых значений.

В группе **«ДДС»** заполните те же поля для отчёта ДДС и БДДС.

Настройка действует с указанного месяца и до следующей записи. Если структура отчёта в компании менялась, заведите запись на каждый период: ассистент сам выберет структуру, которая действовала в запрошенном месяце. Все записи видны по ссылке **«История»**.

:::info 

Если за запрошенный период структура не указана, ассистент получит ошибку `STRUCTURE_NOT_SET`. Заполните настройку с месяца, с которого в базе есть данные.

:::

Ассистент может запросить и другую структуру, если назвать её в вопросе: «посчитай выручку по структуре „Основная структура P&L“».

### Шаг 5. Подключите ассистента

На компьютере, с которого сотрудник работает с ассистентом:

1. Установите **Node.js** версии 18 или новее с сайта nodejs.org.

2. Скачайте архив с файлами MCP-сервера P&L и распакуйте его в папку, например `C:\PNL-MCP`. Папку `design` держите рядом с файлом `index.js`: без неё сервер не запустится.

3. Добавьте сервер в настройки ассистента. Для Claude Desktop это файл `claude_desktop_config.json` (**Настройки → Developer → Edit Config**), для Claude Code -- файл `.mcp.json` в папке проекта:

```json
{
  "mcpServers": {
    "pnl": {
      "command": "node",
      "args": ["C:/PNL-MCP/index.js"],
      "env": {
        "PNL_MCP_URL": "http://<адрес сервера>/<имя публикации>/hs/mcp_pnl/v2",
        "PNL_MCP_USER": "<пользователь 1С из шага 2>",
        "PNL_MCP_PASSWORD": "<пароль>"
      }
    }
  }
}
```

Путь к `index.js` пишется через прямые слеши. Логин на русском языке перекодировать не нужно.

4. Перезапустите ассистента. Список инструментов он получает при запуске.

:::info 

Архив с файлами MCP-сервера P&L: *ссылка будет добавлена*

:::

### Шаг 6. Проверьте подключение

Спросите ассистента: «Проверь подключение к P&L». Он вызовет проверку сервиса и покажет, с какой базой работает, какие структуры отчётов действуют и сколько инструментов доступно.

Проверить сервис без ассистента можно в браузере: откройте адрес `http://<адрес сервера>/<имя публикации>/hs/mcp_pnl/v2/health` и введите логин и пароль пользователя из шага 2.

## Если что-то не работает

| Что видно | Причина |
|---|---|
| Ассистент не видит инструментов P&L | Ассистент не перезапущен после правки настроек или неверный путь к `index.js` |
| «Нет связи с 1С» | База не опубликована, HTTP-сервисы расширений не опубликованы или неверный адрес в `PNL_MCP_URL` |
| Ошибка 401 | Неверный логин или пароль |
| `TOOL_DISABLED`: «Сервис MCP выключен в настройках модуля» | Снят флажок «Использовать MCP сервис» |
| `TOOL_DISABLED`: «Функционал доступен только в версии КОРП» | Версия продукта ниже КОРП |
| `STRUCTURE_NOT_SET` | На запрошенный месяц в блоке «MCP» не указана структура отчёта |
| План по БДР или БДДС нулевой | План заведён в другой структуре. Попросите ассистента посчитать по ней или укажите её в настройках |
| Ошибка прав доступа | У пользователя из шага 2 не хватает ролей |
