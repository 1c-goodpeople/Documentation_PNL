MCP соединяет модуль P&L в 1С с ИИ-помощником. Вы задаёте вопрос обычными словами, а помощник получает нужные данные из вашей базы и отвечает с цифрами. Например: «Покажи выручку и чистую прибыль по месяцам за первое полугодие» или «Какие платежи просрочены сегодня?»

Помощник может запросить ОПиУ, ДДС, БДР, БДДС, платёжный календарь, сведения о проектах и договорах. MCP P&L работает **только на чтение**: через него ИИ не изменяет данные в 1С.

| Данные | Пример вопроса |
|---|---|
| ОПиУ | «Как менялась выручка и чистая прибыль по месяцам?» |
| ДДС | «Сколько денег поступило и сколько потратили в июне?» |
| БДР и БДДС | «Сравни план и факт за второй квартал». |
| Платёжный календарь | «Какие платежи просрочены?» |
| Проекты | «Какие проекты вышли за смету?» |
| Договоры | «Какие платежи запланированы по договору?» |

Цифры ОПиУ, ДДС и бюджетов зависят от структур отчётов, которые настроены в этой базе.

:::info

MCP доступен в версии **КОРП**. Для подключения нужна база 1С с актуальным расширением P&L и программа с поддержкой локального MCP на компьютере пользователя.

:::
