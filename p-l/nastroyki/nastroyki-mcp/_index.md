MCP соединяет модуль P&L в 1С с ИИ-помощником. Вы задаёте вопрос обычными словами, а помощник получает нужные данные из вашей базы и отвечает с цифрами. Например: «Покажи выручку и чистую прибыль по месяцам за первое полугодие» или «Какие платежи просрочены сегодня?»

Помощник может запросить ОПиУ, ДДС, БДР, БДДС, платёжный календарь, сведения о проектах и договорах, взаиморасчёты с контрагентами. Эти запросы работают **только на чтение**: при получении показателей ИИ не изменяет данные в 1С.

| Данные | Пример вопроса |
|---|---|
| ОПиУ | «Как менялась выручка и чистая прибыль по месяцам?» |
| ДДС | «Сколько денег поступило и сколько потратили в июне?» |
| БДР и БДДС | «Сравни план и факт за второй квартал». |
| Платёжный календарь | «Какие платежи просрочены?» |
| Проекты | «Какие проекты вышли за смету?» |
| Договоры | «Какие платежи запланированы по договору?» |
| Взаиморасчёты | «Сколько мы должны поставщикам по бухгалтерскому учёту на конец месяца?» |

Цифры ОПиУ, ДДС и бюджетов зависят от структур отчётов, которые настроены в этой базе.

### Взаиморасчёты через MCP

Доступны три отдельных запроса: **остатки на дату**, **обороты за период** и **все документы**. Остатки показывают долги обеих сторон. Обороты объясняют изменение долга от начала до конца периода. Документы позволяют увидеть начисления, оплаты, возвраты и корректировки, в том числе по закрытым расчётам. Для управленческого учёта это история движений документов; остаток долга по каждому отдельному документу не распределяется.

В запросе укажите вид учёта:

- **Бухгалтерский** — стандартные данные 1С. В Бухгалтерии предприятия используются счета 60, 62 и 76 с субсчетами; в УНФ и УТ — типовые взаиморасчёты этих конфигураций.
- **Управленческий P&L** — данные управленческих взаиморасчётов модуля P&L. Для их включения должна быть задана дата начала учёта взаиморасчётов. В разделе **P&L → Настройки → MCP** выберите структуру ОПиУ: из неё берётся метод каждой статьи. Для статьи вне структуры применяется метод начисления.

Если вид учёта не указан, помощник уточнит его. Если управленческие взаиморасчёты выключены, он сообщит, что данные недоступны. Это не означает нулевой долг. Бухгалтерские взаиморасчёты доступны независимо от этой настройки; перейти к ним помощник может с вашего согласия.

Примеры:

- «Покажи по бухгалтерскому учёту наш долг перед поставщиками на 31 октября».
- «Покажи по управленческому учёту обороты и все документы по контрагенту за октябрь».

:::info

MCP доступен в версии **КОРП**. Для подключения нужна база 1С с актуальным расширением P&L и программа с поддержкой локального MCP на компьютере пользователя.

:::
