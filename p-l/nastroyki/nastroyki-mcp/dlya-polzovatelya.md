### Сначала проверьте, подходит ли ваша программа с ИИ

Эта папка работает с **программой на вашем компьютере, которая умеет запускать локальный MCP-сервер (`stdio`)**. Например, это может быть Claude Desktop, Claude Code, Cursor, VS Code с поддержкой MCP или Codex с локальным MCP-подключением. Нужна именно поддержка локальных MCP в выбранной программе. **Обычный чат в браузере или приложение на телефоне не запустят папку с вашего компьютера.** При этом сама модель ИИ может работать через интернет: локально запускается папка MCP.

Эти шаги рассчитаны на **Windows**. Расширение 1С устанавливает администратор; скачивать его вместе с папкой не нужно.

### 1\. Получите папку и доступ

Администратор даст вам ссылку на архив, адрес базы, логин, пароль и **личный токен**. Токен относится к конкретной базе. Если у вас две базы, попросите отдельный токен для каждой.

**Скачать папку MCP для Windows:** **\[ссылка будет добавлена\]**.

Распакуйте архив в свою папку на компьютере, например в **Документы**. Внутри уже есть нужный `node.exe`: **устанавливать Node.js отдельно не нужно**. После подключения к ИИ не переносите папку -- программа будет запускать файлы по её текущему пути.

### 2\. Заполните четыре строки

Откройте в папке файл `Настройки.txt` обычным Блокнотом. После каждого знака `=` впишите данные от администратора:

```text
Адрес=https://ваш-сервер/имя-публикации/hs/mcp_pnl
Логин=логин 1С
Пароль=пароль 1С
Токен=личный токен MCP
```

Сохраните файл. Пароль может быть пустым, если так настроено подключение к 1С. Адрес и токен должны быть от **одной и той же базы**.

### 3\. Проверьте связь с 1С

Дважды нажмите `Проверить.cmd` в этой же папке. Если появилось сообщение **«Связь с 1С есть»**, переходите дальше. Если появилась ошибка, отправьте администратору **текст ошибки**. Не отправляйте заполненный `Настройки.txt`: в нём находятся пароль и токен.

### 4\. Подключите папку к ИИ

Откройте установленную программу с ИИ. Скопируйте **полный путь к распакованной папке** и вставьте в текст ниже вместо `<путь к папке>`. Затем отправьте весь текст своему ИИ:

:::quote

Помоги подключить P&L MCP к твоей программе на Windows. Папка находится здесь: `<путь к папке>`. Данные для входа уже записаны в `Настройки.txt`. Не открывай этот файл и не показывай его содержимое в чате.

Проверь, поддерживает ли твоя программа локальный MCP через `stdio`. Если да, добавь сервер с именем `pnl-mcp`: команда -- полный путь к `node.exe` в этой папке, единственный аргумент -- полный путь к `bootstrap.mjs` в ней же. Сохрани мои другие MCP-подключения. Если ты не можешь изменить настройки сам, покажи мне, куда нажать в этой программе.

После подключения перезапусти MCP или попроси меня перезапустить программу. Вызови инструменты `health` и `list_structures` и скажи, есть ли связь с моей базой. Ничего не изменяй в 1С.

:::

Если ИИ попросит заполнить настройки MCP вручную, укажите:

| Поле | Что указать |
|---|---|
| Тип подключения | Локальный MCP (`stdio`) |
| Имя | `pnl-mcp` |
| Команда | Полный путь к `node.exe` **в распакованной папке** |
| Аргумент | Полный путь к `bootstrap.mjs` **в той же папке** |

Пароль и токен в настройках ИИ писать повторно не нужно: запускатель берёт их из `Настройки.txt`. После добавления MCP перезапустите программу с ИИ или переподключите MCP. Теперь можно спросить, например: **«Через P&L MCP покажи выручку и чистую прибыль по месяцам за этот год»**.

### Что делать потом

Новые инструменты и обновления адаптера приходят из расширения P&L в вашей базе. В обычной работе повторно скачивать папку не нужно. Если после обновления базы программа попросит переподключить MCP или перезапуститься, сделайте это.

Если `Проверить.cmd` показывает связь, а ИИ не видит MCP, проверьте поддержку **локального `stdio`**, пути к `node.exe` и `bootstrap.mjs` и перезапустите ИИ. Если токен потерян или перестал работать, попросите администратора выпустить новый.

Заполненная папка содержит пароль и токен. Храните её у себя и не пересылайте другим людям; для другого пользователя нужен чистый архив и его личный токен.
