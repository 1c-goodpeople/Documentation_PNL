Документ **«Операция, введённая вручную»** в конфигурации **«Бухгалтерия предприятия»**. Используется для ручного отражения операции в P&L по сохранённым строкам распределения.

Общий порядок применения правил: [как заполняются реквизиты документов](../kak-zapolnyayutsya-rekvizity-dokumentov). Здесь приведён порядок для этого документа.

## Как заполняются реквизиты документа: приоритетность заполнения

### Дата

1. Из строки ручного распределения.
2. Из даты операции, если дата в строке не заполнена.

### Статья, организация, подразделение, контрагент, договор, проект, раздел, доп. аналитика, сумма

1. Из сохранённой строки ручного распределения.

### Вид движения

Поступление отражается как доход, списание — как расход. Используется метод начисления.

## Особенности документа

- Движения P&L формируются из сохранённых строк ручного распределения при записи операции. Дата строки → дата операции; статья, сумма, организация, подразделение, контрагент, договор и аналитики — из строки. Автоматического выбора по бухгалтерскому счёту здесь нет.

## Контроль результата

После заполнения проверьте статью, сумму, период и аналитику движений P&L. Исключённая статья не заменяется умолчанием. Для пересчёта существующих данных применяйте явную команду P&L; изменение настройки само по себе не пересчитывает прошлые документы.
