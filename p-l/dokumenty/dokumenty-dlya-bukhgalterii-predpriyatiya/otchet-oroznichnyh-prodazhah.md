Документ **«Отчёт о розничных продажах»** в конфигурации **«Бухгалтерия предприятия»**. Отражает розничную выручку и отдельно себестоимость проданных товаров. Статья выручки и статья себестоимости выбираются независимо.

Общий порядок применения правил: [как заполняются реквизиты документов](../kak-zapolnyayutsya-rekvizity-dokumentov). Здесь приведён порядок для этого документа.

## Как заполняются реквизиты документа: приоритетность заполнения

### Статья

1. Из строки табличной части документа.
2. Из шапки документа, если статья в строке не заполнена.
3. Из подходящего правила регистра «Соответствие параметров и статей ДДС», если статья не заполнена ни в строке, ни в шапке.
4. Из типовой статьи документа, если статья не найдена в первых трёх источниках.

Где заполняется: шапка документа; таблица «Товары»; таблица «Агентские услуги».

### Доп. аналитика, проект и раздел проекта

1. Из строки табличной части документа.
2. Из шапки документа, если соответствующий реквизит в строке не заполнен.
3. Из подходящего правила регистра «Соответствие параметров и статей ДДС», если реквизит не заполнен ни в строке, ни в шапке.

Где заполняется: шапка документа; таблица «Товары»; таблица «Агентские услуги».

### Дата принятия к управленческому учёту

1. Из поля «Дата принятия к управленческому учёту» в шапке документа.
2. Из даты документа, если дата принятия к управленческому учёту не заполнена.

При обычном расчёте по начислению используется этот порядок. При ручном распределении дата выбирается из строки распределения.

### Статья себестоимости

1. Из подходящей строки таблицы «Товары».
2. Из шапки документа, если статья себестоимости в строке не заполнена.
3. Из подходящего правила регистра «Соответствие параметров и статей ДДС», если статья не заполнена ни в строке, ни в шапке. Используется непустая статья себестоимости из наиболее конкретного подходящего соответствия.
4. Из настройки «Статья себестоимости по умолчанию», если статья не найдена в первых трёх источниках.

Где заполняется: шапка документа; таблица «Товары».

**Статья себестоимости по умолчанию подставляется только в движения.** Она не заполняет пустую шапку или строки документа.

## Заполнение и запись

Значения задаются в доступном блоке «Реквизиты P&L» и реквизитах строки, где они предусмотрены. Автоправило ОПиУ с непустым значением может изменить поле шапки до сохранения; движение читает уже сохранённое значение. Этот этап отличается от выбора следующего источника для пустого поля.

- При копировании дата принятия к управленческому учёту очищается. Для новой копии проверьте период отражения отдельно.

## Особенности документа

- Для основной статьи выручки: строка → шапка P&L → соответствие параметров БП → типовая статья документа. Для проекта, раздела и доп. аналитики последний источник — соответствие.
- Поля агентских услуг используются для выручки, а себестоимость рассчитывается по товарам.
- Для себестоимости берётся первая подходящая строка по номенклатуре и группе. Повторные одинаковые товары с разными статьями требуют проверки итоговых бухгалтерских сумм.

## Контроль результата

После заполнения проверьте статью, сумму, период и аналитику движений P&L. Исключённая статья не заменяется умолчанием. Для пересчёта существующих данных применяйте явную команду P&L; изменение настройки само по себе не пересчитывает прошлые документы.
