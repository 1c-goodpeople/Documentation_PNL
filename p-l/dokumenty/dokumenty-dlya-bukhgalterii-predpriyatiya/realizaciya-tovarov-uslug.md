Документ **«Реализация товаров и услуг»** в конфигурации **«Бухгалтерия предприятия»**. Отражает выручку и отдельно себестоимость товаров. Основная статья и статья себестоимости имеют самостоятельные источники.

Общий порядок применения правил: [как заполняются реквизиты документов](../kak-zapolnyayutsya-rekvizity-dokumentov). Здесь приведён порядок для этого документа.

## Заполнение и запись

Значения задаются в доступном блоке «Реквизиты P&L» и реквизитах строки, где они предусмотрены. Автоправило ОПиУ с непустым значением может изменить поле шапки до сохранения; движение читает уже сохранённое значение. Этот этап отличается от выбора следующего источника для пустого поля.

- При копировании дата принятия к управленческому учёту очищается. Для новой копии проверьте период отражения отдельно.
- Если дата по графику не заполнена, при записи в неё подставляется дата документа.

## Особенности документа

- Обычные реквизиты выручки в товарах, услугах и смете: строка → шапка → соответствие параметров БП. Для агентских услуг используются строка и шапка.
- Статья себестоимости в таблице «Услуги» не участвует в расчёте себестоимости: эта ветка читает только «Товары».
- Бухгалтерская сумма связывается с первой подходящей строкой товаров по номенклатуре и группе. Если один товар повторён с разными статьями, агрегированная проводка автоматически не делится между всеми такими строками.
- После обычной себестоимости реализация может закрыть НЗП по совпадающим проекту и разделу дохода. Пустой раздел и раздел «Монтаж» — разные аналитики.

## Контроль результата

После заполнения проверьте статью, сумму, период и аналитику движений P&L. Исключённая статья не заменяется умолчанием. Для пересчёта существующих данных применяйте явную команду P&L; изменение настройки само по себе не пересчитывает прошлые документы.
