## Как заполняются реквизиты документа: приоритетность заполнения

При формировании движений P&L каждый реквизит выбирается отдельно. Если он не заполнен в первом источнике, используется следующий по списку.

### Статья, доп. аналитика, проект и раздел проекта

1. Из строки табличной части документа.
2. Из шапки документа, если соответствующий реквизит в строке не заполнен.
3. Из подходящего правила регистра «Соответствие параметров и статей ДДС», если соответствующий реквизит не заполнен ни в строке, ни в шапке.

Этот порядок применяется к таблицам «Товары», «Услуги» и «Смета». Для таблицы «Агентские услуги» используются только первые два источника: строка и шапка.

Например, статья может быть взята из строки, а проект — из шапки, если проект в этой строке не указан.

### Дата принятия к управленческому учёту

1. Из поля «Дата принятия к управленческому учёту» в шапке документа.
2. Из даты документа, если дата принятия к управленческому учёту не заполнена.

Этот порядок применяется при обычном расчёте по начислению. При ручном распределении используется дата строки распределения. При копировании документа дата принятия к управленческому учёту очищается.

### Дата по графику

1. Используется дата, указанная в шапке документа.
2. Если поле пустое, при записи в него подставляется дата документа.

Дата по графику сама по себе не заменяет дату фактического движения P&L.

## Как заполняется статья себестоимости

1. Из подходящей строки таблицы «Товары».
2. Из шапки документа, если статья себестоимости в строке не заполнена.
3. Из подходящего правила регистра «Соответствие параметров и статей ДДС», если статья себестоимости не заполнена ни в строке, ни в шапке. Используется непустая статья себестоимости из наиболее конкретного подходящего соответствия.
4. Из настройки «Статья себестоимости по умолчанию», если статья не найдена в первых трёх источниках.

**Статья себестоимости по умолчанию подставляется только в движения.** Она не заполняет пустую шапку или строки документа.

Строки «Услуги» в выборе статьи себестоимости не участвуют.

При расчёте бухгалтерская сумма себестоимости связывается с первой подходящей строкой товаров по номенклатуре и группе. Если один товар указан в нескольких строках с разными статьями, общая сумма проводки автоматически между этими строками не распределяется.

## Как влияют автоправила ОПиУ

Автоправила ОПиУ заполняют реквизиты шапки перед записью документа. При автоматическом заполнении без подтверждения правило может заменить уже заполненное значение.

После этого при формировании движений применяется порядок, описанный выше: заполненная строка имеет приоритет, затем используется шапка, в том числе значения, которые в неё внесло автоправило.

## Как закрывается НЗП

При включённом учёте НЗП реализация может дополнительно списать накопленные затраты по проекту и разделу проекта дохода. Проект и раздел должны совпадать с аналитикой накопленных затрат. Например, пустой раздел и раздел «Монтаж» считаются разными значениями.
