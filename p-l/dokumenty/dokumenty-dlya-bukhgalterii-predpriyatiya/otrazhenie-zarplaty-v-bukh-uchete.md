Документ «Отражение зарплаты в бухучете» учитывает начисленную зарплату и страховые взносы в расходах PnL, когда учёт зарплаты ведётся во внешней программе. Для каждого вида суммы можно указать отдельную статью: основную статью зарплаты, статью взносов по единому тарифу и статью взносов от несчастных случаев. Документ обычно поступает из внешней программы: заполнять его строки вручную для работы соответствий не требуется.

## Реквизиты P&L в строках начислений

В таблице «Начисленная зарплата и взносы» у каждой строки есть ссылка **«Реквизиты PnL»**. Нажмите её, чтобы задать три статьи, дополнительную аналитику, проект и раздел проекта именно для этой строки. В таблице показана одна компактная колонка, без шести отдельных колонок. Реквизиты в шапке документа задают общие значения. Пустые поля строки можно оставить незаполненными: система определит их при проведении.

Для **каждого реквизита отдельно** действует порядок:

1. Заполненное значение в строке таблицы.
2. Если оно пустое — значение в шапке документа.
3. Если и шапка пустая — значение из подходящего соответствия.

Например, если в строке задана только основная статья, она останется ручной, а статья взносов и аналитика могут прийти из шапки или соответствия. Пустые поля одного правила не заполняются из других правил.

При проведении подбор выполняется для движений PnL **без записи вычисленных значений в строки документа**. Заполненные в строке значения сохраняют приоритет и не заменяются правилом.

## Соответствие параметров заработной платы по статьям

Откройте **Настройки → P&L → ОПиУ → Учёт заработной платы → Соответствие параметров заработной платы по статьям**. В условии правила укажите подразделение, вид операции, способ отражения зарплаты в бухучёте и вид начисления для налогового учёта. Необязательные условия можно оставить пустыми. Старые правила без вида операции подходят для любого вида операции. В результате задайте статьи зарплаты и взносов, дополнительную аналитику, проект и раздел.

Для каждой строки начислений соответствие ищется по четырём условиям строки, включая вид операции. Если подходят несколько записей, применяется наиболее точная по числу совпавших заполненных условий. При равной точности нескольких записей соответствие неоднозначно и не применяется. Если основная статья уже есть в строке или шапке, отсутствие правила само по себе не мешает движениям PnL. Из выбранной записи берутся только поля, оставшиеся пустыми после проверки строки и шапки.

## Заполнить реквизиты PnL

В панели таблицы «Начисленная зарплата и взносы» находятся команды **«Заполнить реквизиты PnL»** и **«Настроить соответствия PnL»** с иконкой PnL. Команда заполнения позволяет проверить строки до проведения. При повторном нажатии она заменяет **все шесть реквизитов в каждой содержательной строке**, в том числе введённые вручную: берёт значение из шапки, затем из правила. После заполнения колонка «Реквизиты PnL» обновляется. Команда сама не записывает и не проводит документ; для сохранения изменений запишите его. Если в строке с суммой не определена основная статья, команда сообщает о проблеме и не перезаполняет ни одну строку.

## НДФЛ

«Начисленный НДФЛ» хранится в отдельной таблице без подразделения строки. Статью НДФЛ задают в шапке документа; соответствие подразделений её не заполняет. Если статья НДФЛ не указана, его сумма остаётся в расходах по основной статье. Если указана, НДФЛ показывается отдельно, а основная зарплатная сумма уменьшается на него.

## Отражение зарплаты по управленческому учёту

При создании «Отражения заработной платы в УУ» на основании этого документа для каждой строки зарплаты и взносов применяется тот же порядок выбора статей и аналитики. Подразделение строки сохраняется. НДФЛ обрабатывается по статье из шапки.

После проведения управленческого документа движения PnL основания очищаются, чтобы расходы не задвоились. Это не удаляет типовые бухгалтерские проводки основания.

## Взаиморасчёты с сотрудниками

Если ведение управленческой зарплаты настроено «По всему учёту», в регистр «Взаиморасчёты с сотрудниками (P&L)» попадает сумма к выплате: начисленная зарплата за вычетом НДФЛ. НДФЛ и страховые взносы во взаиморасчёты не включаются.

## Как заполняются реквизиты документа: приоритетность заполнения

Документ **«Отражение зарплаты в бухучёте»** в конфигурации **«Бухгалтерия предприятия»**. Отражает зарплату, НДФЛ и взносы по данным отражения в бухучёте. Для зарплатных строк статья и аналитика могут уточняться отдельно.

Общий порядок применения правил: [как заполняются реквизиты документов](../kak-zapolnyayutsya-rekvizity-dokumentov). Здесь приведён порядок для этого документа.

### Статья

1. Из строки зарплатной таблицы.
2. Из шапки документа, если статья в строке не заполнена.
3. Из выбранного соответствия подразделению, виду операции, способу отражения зарплаты и виду начисления для налогового учёта, если статья не заполнена ни в строке, ни в шапке.

Где заполняется: шапка документа; таблица «Начисленная зарплата и взносы».

Каждый реквизит выбирается отдельно. Используется одно подходящее соответствие; его пустые поля не дополняются из других соответствий.

### Статьи взносов, доп. аналитика, проект и раздел проекта

1. Из строки зарплатной таблицы.
2. Из шапки документа, если соответствующий реквизит в строке не заполнен.
3. Из выбранного соответствия подразделению, виду операции, способу отражения зарплаты и виду начисления для налогового учёта, если реквизит не заполнен ни в строке, ни в шапке.

Где заполняется: шапка документа; таблица «Начисленная зарплата и взносы».

Каждый реквизит выбирается отдельно. Используется одно подходящее соответствие; его пустые поля не дополняются из других соответствий.

### Дата принятия к управленческому учёту

1. Из поля «Дата принятия к управленческому учёту» в шапке документа.
2. Из даты документа, если дата принятия к управленческому учёту не заполнена.

При обычном расчёте по начислению используется этот порядок. При ручном распределении дата выбирается из строки распределения.

### Создана управленческая операция

Служебный признак создания управленческого документа на основании. После проведения управленческого документа отражение исходного документа может прекращаться, чтобы суммы не задваивались.

### Статья НДФЛ

1. Из поля «Статья НДФЛ» в шапке документа.

Если отдельная статья не задана, НДФЛ остаётся в общей статье расходов. Его сумма не увеличивает сумму к выплате сотруднику.

### Отражать в нзп

1. Из признака «Отражать в НЗП» в документе.

Перенос в НЗП требует включённых настроек НЗП и учёта проектов, метода начисления, заполненного проекта и даты не раньше начала использования НЗП.

## Заполнение и запись

Значения задаются в доступном блоке «Реквизиты P&L» и реквизитах строки, где они предусмотрены. Автоправило ОПиУ с непустым значением может изменить поле шапки до сохранения; движение читает уже сохранённое значение. Этот этап отличается от выбора следующего источника для пустого поля.

- При копировании дата принятия к управленческому учёту очищается. Для новой копии проверьте период отражения отдельно.

## Особенности документа

- Основная статья, статьи взносов и аналитики: строка → шапка → выбранное соответствие по четырём условиям, включая вид операции.
- Статья НДФЛ — из шапки: отдельного реквизита НДФЛ в таблице «Начисленная зарплата и взносы» нет.

## Контроль результата

После проведения проверьте статьи, суммы, период и аналитику движений PnL. Если основная статья отсутствует хотя бы в одной строке с ненулевой суммой зарплаты или взносов, все движения PnL этого документа очищаются. Проверка PnL не запрещает стандартное проведение и не удаляет бухгалтерские проводки. Если отсутствует только отдельная статья взносов, пропускается расход PnL по этому виду; зарплата и другой вид взносов сохраняются. После изменения правила перепроведите документ, чтобы пересчитать движения.
