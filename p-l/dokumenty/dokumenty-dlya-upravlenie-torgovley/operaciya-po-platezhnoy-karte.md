Документ **«Операция по платежной карте»** в конфигурации **«Управление торговлей»**. Может быть источником расходов P&L через типовой регистр «Прочие расходы». Переносится признанный расход; вся сумма документа автоматически не включается в ОПиУ.

Общий порядок применения правил: [как заполняются реквизиты документов](../kak-zapolnyayutsya-rekvizity-dokumentov). Здесь приведён порядок для этого документа.

## Реквизиты и приоритеты

Дополнительных полей статьи, проекта и раздела P&L в шапке нет. Автоматический перенос использует следующие источники:

| Значение движения P&L | Источник |
|---|---|
| Статья расхода | Соответствие типовой статьи расходов УТ статье ДДС |
| Период, организация, подразделение | Типовое движение «Прочие расходы» |
| Сумма | Способ учёта: управленческий учёт / регламентированный учёт / сумма документа / сумма документа без НДС |
| Проект, раздел, доп. аналитика | Общий перенос «Прочих расходов» не подставляет их из шапки этого документа |

## Заполнение и запись

При записи «Прочих расходов» рассматриваются приходные строки признанного расхода. По типовой статье расходов находится соответствие статье ДДС. Непустая не исключённая статья используется в начисленном расходе P&L; строка без подходящей статьи не переносится.

Этот механизм не заполняет статью себестоимости в документе и не использует соответствия параметров БП. Настраивайте соответствие статей затрат/расходов и статей ДДС; контролируйте результат на вкладке «Расходы».

## Контроль результата

После заполнения проверьте статью, сумму, период и аналитику движений P&L. Исключённая статья не заменяется умолчанием. Для пересчёта существующих данных применяйте явную команду P&L; изменение настройки само по себе не пересчитывает прошлые документы.
