Документ **«Акт выполненных работ»** в конфигурации **«Управление торговлей»**. Отражает доход от выполненных работ по основной статье P&L. Наличие услуг в документе само по себе не создаёт отдельного движения себестоимости.

Общий порядок применения правил: [как заполняются реквизиты документов](../kak-zapolnyayutsya-rekvizity-dokumentov). Здесь приведён порядок для этого документа.

## Реквизиты и приоритеты

| Реквизит | Где задаётся | Как используется и какой источник выше |
|---|---|---|
| Дата принятия к управленческому учёту | Шапка | Дата УУ → дата документа в обычном начисленном расчёте. Дата строки ручного распределения выбирается отдельным путём. |
| Доп. аналитика | Шапка | Сохранённое значение шапки после заполнения на основании, ручного ввода и подходящего автоправила. |
| Проект | Шапка | Сохранённое значение шапки после заполнения на основании, ручного ввода и подходящего автоправила. |
| Раздел проекта | Шапка | Сохранённое значение шапки после заполнения на основании, ручного ввода и подходящего автоправила. |
| Статья P&L | Шапка | Сохранённая статья P&L шапки; пустая статья при записи может заполняться статьёй по умолчанию договора. |

## Заполнение и запись

Значения задаются в доступном блоке «Реквизиты P&L» и реквизитах строки, где они предусмотрены. Автоправило ОПиУ с непустым значением может изменить поле шапки до сохранения; движение читает уже сохранённое значение. Этот этап отличается от выбора следующего источника для пустого поля.

- При копировании дата принятия к управленческому учёту очищается. Для новой копии проверьте период отражения отдельно.

## Особенности документа

- Пустая основная статья P&L перед записью может заполняться статьёй по умолчанию договора. Расчёт затем читает сохранённую статью шапки.

## Контроль результата

После заполнения проверьте статью, сумму, период и аналитику движений P&L. Исключённая статья не заменяется умолчанием. Для пересчёта существующих данных применяйте явную команду P&L; изменение настройки само по себе не пересчитывает прошлые документы.
