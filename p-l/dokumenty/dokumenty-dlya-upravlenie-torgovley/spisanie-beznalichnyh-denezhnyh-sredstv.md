Документ **«Списание безналичных денежных средств»** в конфигурации **«Управление торговлей»**. Отражает фактическое движение денег по операции и типовым данным. Доходы, расходы, комиссия и расчёты определяются отдельными ветками; денежное движение не равнозначно себестоимости товаров.

Общий порядок применения правил: [как заполняются реквизиты документов](../kak-zapolnyayutsya-rekvizity-dokumentov). Здесь приведён порядок для этого документа.

## Реквизиты и приоритеты

| Реквизит | Где задаётся | Как используется и какой источник выше |
|---|---|---|
| Доп. аналитика | Шапка | Реквизиты P&L шапки после создания из основания, ввода и применения правила ДДС; ручное распределение использует свои строки. |
| Проект | Шапка | Реквизиты P&L шапки после создания из основания, ввода и применения правила ДДС; ручное распределение использует свои строки. |
| Раздел проекта | Шапка | Реквизиты P&L шапки после создания из основания, ввода и применения правила ДДС; ручное распределение использует свои строки. |
| Фонд | Шапка | Явный фонд документа/ручного распределения используется в применимой ветке. При пустом фонде используются настроенные режим и схемы фондов с учётом даты включения и вида операции. |

## Заполнение и запись

Значения задаются в доступном блоке «Реквизиты P&L» и реквизитах строки, где они предусмотрены. Подходящее правило ДДС изменяет распределение и аналитику перед расчётом. Если дополнительно настроено автоправило реквизитов, его непустое значение может заменить поле шапки до сохранения. Движение читает результат этих действий.

Основное распределение денежного документа выполняется правилом **ДДС**: оно может разделить сумму по статьям и заполнить аналитику. Ручное распределение использует сохранённые строки.

### Типовые реквизиты денежного движения

| Реквизит | Источник и порядок |
|---|---|
| Статья ДДС | Статья строки расшифровки платежа → типовая статья шапки. Для операций с расчётом по полной сумме без подходящей расшифровки используется статья шапки. |
| Проект, раздел, доп. аналитика | Поля P&L шапки; в ручном режиме — сохранённая строка распределения |
| Дата | Дата проведения банком; ручная строка может задавать собственную дату |
| Организация | Организация документа |
| Счёт / касса, валюта | Банковский счёт или касса и валюта денежной операции |
| Контрагент и договор | Типовые данные операции и расшифровки платежа |
| Сумма | Сумма расшифровки / полная типовая сумма операции, с переводом валюты по соответствующему курсу |

Для зарплаты, налогов, комиссии, переводов между счетами и прочих специальных операций применяются собственные типовые данные операции и настройки соответствующих статей. Статья обычного платежа не заменяет самостоятельную статью комиссии или начисленной зарплаты.

При проведении читаются фактические типовые суммы и данные операции. Изменение правила или аналитики без пересчёта не меняет старые движения автоматически.

## Контроль результата

После заполнения проверьте статью, сумму, период и аналитику движений P&L. Исключённая статья не заменяется умолчанием. Для пересчёта существующих данных применяйте явную команду P&L; изменение настройки само по себе не пересчитывает прошлые документы.
