title: Настройка маршрута согласования
---

Маршрут определяет, кто и в каком порядке согласует документ. Без маршрута документ не уйдёт на согласование: система выдаст сообщение «Для этого типа объекта не найден маршрут согласования. Обратитесь к администратору».

Маршруты настраивает администратор один раз. Дальше система сама подбирает нужный маршрут при каждой отправке.

## Где находится

**1C:P&L → Согласование → Маршруты согласования**

## Что можно согласовывать

- заявки на оплату;
- реестры платежей;
- договоры контрагентов.

Для каждого вида нужен свой маршрут.

## Поля маршрута

### Наименование

Название маршрута для списка. Пишите так, чтобы было понятно, когда он срабатывает: «Оплаты до 100 000 ₽», «Реестр — ООО МебельДомТорг».

### Вид объекта и Тип

Сначала выберите вид объекта — «Документ» или «Справочник». Затем в поле «Тип» выберите конкретный документ. В списке типов только то, что поддерживает согласование.

Если сменить вид объекта, тип очистится — выберите его заново.

### Дата начала

С какой даты маршрут действует. Документы, отправленные раньше этой даты, по нему не пойдут.

Дата начала участвует в подборе маршрута: если под документ подходят несколько маршрутов, система выберет тот, у которого дата начала самая поздняя. Поэтому новый маршрут на смену старому достаточно завести с более поздней датой — старый удалять не нужно.

### Условия

Блок над таблицей этапов. Здесь задаётся, для каких документов маршрут подходит. Например, «Организация равно ООО МебельДомТорг» — тогда маршрут сработает только для документов этой организации.

- **Добавить новый элемент** — новое условие.
- **Сгруппировать условия** — объединить условия в группу «И» или «ИЛИ».

Если условий нет, маршрут подходит для всех документов выбранного типа.

## Этапы и согласующие

Таблица внизу формы. Одна строка — один этап.

Этапы идут строго по очереди. Пока не закрыт этап 1, согласующие этапа 2 документ не видят. Внутри этапа все согласующие получают документ одновременно.

### Колонки таблицы

| Колонка | Что значит |
|---|---|
| Этап | Номер этапа. Проставляется автоматически при добавлении строки |
| Наименование этапа | Название, например «Проверка бухгалтерией» |
| Правило завершения | Сколько решений нужно, чтобы этап закрылся |
| Кворум | Число согласий для правила «Кворум». Для других правил недоступно |
| Согласующие | Кто согласует на этом этапе. Нажмите на ссылку, чтобы выбрать людей |

### Как добавить этап

1. Нажмите **Добавить**. Номер, наименование и правило «Все согласующие» подставятся сами.
2. Исправьте наименование этапа, если нужно.
3. Нажмите на ссылку **«<Указать согласующих>»** в строке этапа.
4. В окне подбора перенесите нужных людей в правый список кнопкой **>** и нажмите **Выбрать**.

Выбранный состав заменяет прежний. Чтобы убрать человека с этапа, откройте подбор и уберите его из правого списка кнопкой **<**.

Ссылка срабатывает по клику на выделенной строке. Если строка не выделена, первый клик её выделит, второй откроет подбор.

### Правила завершения

**Все согласующие.** Этап закрывается, когда согласовали все. Если кто-то отклонил — этап отклонён.

**Любой из согласующих.** Этап закрывается после первого согласия. Остальным решение уже не нужно, у них в истории появится «Шаг не требуется». Отклонение одного согласующего этап не закрывает: этап отклоняется, только если отклонили все.

**Кворум.** Этап закрывается, когда набрано нужное число согласий. Число указывается в колонке «Кворум».

Пример: на этапе четыре человека, кворум 2. Как только любые двое согласовали, этап закрыт. Если отклонили трое, набрать два согласия уже невозможно — этап отклоняется сразу, не дожидаясь четвёртого.

Кворум не может быть больше числа согласующих на этапе.

### Названия этапов

Если наименование этапа пустое или совпадает с «Этап 1», «Этап 2», в схеме маршрута он покажется как «Шаг 1», «Шаг 2». Схема читается лучше, когда этапы названы по смыслу: «Проверка бухгалтерией», «Утверждение руководителем», «Казначейство».

## Проверки при записи

Маршрут не запишется, пока в нём есть ошибка. Система подсветит поле и напишет, что не так:

- не указан тип объекта;
- дата окончания раньше даты начала;
- в маршруте нет ни одного этапа;
- у этапа не указано правило завершения;
- на этапе не назначен ни один согласующий;
- номер этапа повторяется;
- один и тот же человек указан на этапе дважды;
- для правила «Кворум» не указано число;
- кворум больше числа согласующих.

## Как система подбирает маршрут

При отправке документа система ищет маршрут по порядку:

1. Тип маршрута совпадает с типом документа.
2. Маршрут не помечен на удаление.
3. Документ попадает в период действия маршрута.
4. Документ подходит под условия маршрута.

Если подошло несколько маршрутов, берётся тот, у которого дата начала самая поздняя. Пользователь маршрут не выбирает — он видит готовую схему перед отправкой.

## Важно знать

**Инициатор не согласует сам себя.** Если человек, который отправляет документ, стоит согласующим на этапе, его решение ставится автоматически. Если он стоит на всех этапах и один, документ согласуется сразу, без участия других. Проверьте маршрут, чтобы так не получилось случайно.

**Изменения маршрута влияют на документы в работе.** Этапы разворачиваются по мере прохождения. Если поменять согласующих на этапе 3, пока документ ещё на этапе 1, до этапа 3 он дойдёт уже с новым составом. Уже пройденные этапы изменения не затрагивают.

**Старый маршрут лучше не удалять, а заменить.** Заведите новый с более поздней датой начала. Если маршрут больше не нужен совсем — пометьте его на удаление: в подборе он участвовать перестанет, а история по уже согласованным документам сохранится.

**Уведомлений нет.** Система не рассылает письма. Согласующие видят документы в разделе «Мои согласования», в заголовке раздела показано число документов, ожидающих решения.
